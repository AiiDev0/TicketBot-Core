# 🎫 TicketBot Core — Sistema de Tickets Profesional para Discord

**El bot de tickets definitivo, en español, con panel interactivo, transcripciones, calificaciones y automatización.**

> ⚠️ **Nota:** Este repositorio es una vitrina de presentación. El código fuente es privado y se distribuye a través de Gumroad.

## 🎯 El Problema
Los dueños de servidores de Discord pierden horas gestionando tickets manualmente o usando bots en inglés, abandonados y sin soporte.

## 💡 La Solución
**TicketBot Core** es un bot completo que automatiza todo el flujo de soporte:
- Panel interactivo con botones (Soporte, Compras, Reportes).
- Sistema de prioridades con colores.
- Transcripts HTML al cerrar tickets.
- Calificaciones de staff (⭐ 1-5) y comandos `/stats` y `/top`.
- Auto-cierre por inactividad y anti-spam.
- 100% en español.

## 🛠️ Tecnologías
Node.js · Discord.js v14 · MongoDB · Mongoose · dotenv
